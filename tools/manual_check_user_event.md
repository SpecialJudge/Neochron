## 一、把手机接上（一次性）

1. 手机：**设置 → 关于手机 → 连点「版本号」7 次**，打开开发者选项；
2. **设置 → 开发者选项 → 打开「USB 调试」**；
3. 用数据线连电脑（不是只能充电的那种线）；
4. 手机上会弹「**允许 USB 调试吗**」→ 勾选「始终允许」→ 确定。

验证（在你的 PowerShell 里跑）：

```powershell
C:\Android\Sdk\platform-tools\adb devices -l
```

- 看到一行 `xxxxxxx  device ...` → 成功；
- 只有 `unauthorized` → 手机上那个弹窗没点，或点了拒绝（拔插一次会重弹）；
- 什么都没有 → 线/口的问题，换个口试试，或换根线。

> 我在沙箱里查过：**当前没有任何设备连着**（`List of devices attached` 是空的）。

## 二、装上去（一条命令）

```powershell
cd D:\neochron
flutter run --release
```

它会编译 → 安装 → 启动 → 并把日志接到这个终端（Ctrl+C 退出，不影响手机上已装的应用）。

为什么用 `--release` 而不是默认的 debug：

- **与你现在手机上那个应用同签名**。`android/app/build.gradle` 里 release 走的是
  `signingConfigs.release`，而 `android/key.properties` 不在本机 → **自动退回 debug 签名**，
  正好和手机现存版本一致 → **可以直接覆盖安装，不用卸载**（待办/专注记录都留着）；
- 布局与性能是真的（debug 版启动形态不同，看排版没意义）；
- 日志会打到这个终端，出红字我能直接定位。

> 注意：`flutter run`（不带 `--release`）走的是 debug 构建，它的包名带 `.debug` 后缀，
> 会**另装一个应用**、数据也是空的。别用它验收。

**如果你更想直接拿到文件自己装**：

```powershell
cd D:\neochron
flutter build apk --release --target-platform android-arm64 --no-tree-shake-icons
C:\Android\Sdk\platform-tools\adb install -r build\app\outputs\flutter-apk\app-release.apk
```

（`-r` = 覆盖安装，保留数据。如果它报签名不一致，就先导出数据再卸载重装，见 `docs/MIGRATION.md`。）

> ⚠️ 现有的那个 APK 是 **2026-09-25 12:24** 打的，**里面还没有日程功能**
> （代码是 14:26 之后写的），所以必须重跑一次构建。

## 三、看什么（按顺序，每步都能判断对错）

### ① 新建一条例会

待办/日程页 → 右上角 `+` → 应弹出选择：**「待办（要完成的事）」/「日程（到点就发生，比如例会）」**
→ 选**日程**。

编辑页（这里要看的就是"排版对不对"）：

- [ ] 顶部是大字号输入框，提示语是「比如：学生会例会」；
- [ ] 「怎么填时间」那一行有 **按节次 ⇄ 按时刻** 的切换；
- [ ] 「第一次发生在」能点开日历弹窗，**日历上有课程/待办的小圆点**；
- [ ] 「重复」点开是**待办那套弹窗**（每周重复 / 每 N 周 / 无限重复 / 终止于某天）；
- [ ] 新建时「重复到」**已经预填了本学期的最后一天**（这是 SPEC D11）；点「去掉结束日期」会变成「一直重复」；
- [ ] 颜色那行有 4 个色点，**第一个是粉色**，选中的那个圈更粗；
- [ ] 地点、备注能输入；
- [ ] **页面能滚到底**（最下面有一句关于"不跟放假走"的说明）；
- [ ] 右上角「保存」在标题为空时是灰的。

填：标题「学生会例会」、按时刻 **19:00-20:30**、重复**每周** → 保存。

### ② 日历那面

待办/日程页的日历（不是课表）：

- [ ] 今天/下一次那一天（比如下周一）的列表里出现这条日程，**粉色方块**标记；
- [ ] 点它能打开详情（应显示名称、时间、地点）；
- [ ] 月视图的那一天有标记点。

### ③ 课表那面（**这轮的重点**）

右上角那个列表图标切到课表：

- [ ] 课表现在是 **15 行**（第 14 行小字 21:20、第 15 行 22:10）；
- [ ] 在**周一**那一列的**第 11～13 行**出现一张**粉色卡片**，写着「学生会例会」；
- [ ] 卡片**不与课程卡片完全重叠**（如果有课，应并排各占一半宽度）；
- [ ] 字体虽小但**读得出**；地点那行也在；
- [ ] 如果那条日程与课重叠，卡片有**橙色三角角标**；
- [ ] **整体不挤**：15 行比原来的 13 行更矮，课程卡片里的字还看得清吗？

> 2026-09-25 用户拍板把课表从 13 行扩到 15 行（真实校历就是 15 节）。
> 这一改动**只有你真机能判断好坏**：如果太挤，告诉我，我把行高下限再调大
> （现在是 460，矮屏上会变成可滚动）。

### ④ 「接下来」那一面

顶部那个小圆点翻到「接下来」：

- [ ] 这条日程出现在列表里，右边的类型标签是**「日程」**；
- [ ] 显示「还有 N 分钟 / 进行中」这类倒计时。

### ⑤ 编辑与删除

- [ ] 在**日历**里点这条日程 → 应打开**编辑页**（标题写着「编辑日程」，右上角多一个垃圾桶图标）；
- [ ] 改标题或时间 → 保存 → **日历与课表都跟着变**；
- [ ] 点垃圾桶 → 确认弹窗 → 删除后 **日历、课表、「接下来」三处同时消失**；
- [ ] 点左上角 ✕ → 取消，什么都不该变。

> 注：这一段是 2026-09-25 补的 —— 在那之前**点日程卡片什么都不会发生**
> （tap 只服务待办），所以这一步当时是做不到的。

### ⑥（可选）导出与同步

设置 → 数据 → **导出数据** → 得到一份 JSON；用文本编辑器搜 `userEvents`，
应该能看到你刚建的那条。导入同一份文件应提示"新增 0 条"（因为已经在了）。

跨设备（如果你有第二台）：设置 → 局域网同步（`kLanSyncEnabled = true`，
入口是开着的）→ 配对后日程应该能过去，**在一端删掉的不会在另一端复活**。
