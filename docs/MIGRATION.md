# 数据迁移：从 Celechron / Elychron 迁到 Neochron

> 一句话：**课表、成绩、考试、作业、素拓、校园卡这些「服务端数据」登录一下就全有了，不用搬；
> 真正要搬的只有你自己手写的待办。**

先看你的情况属于哪一种：

| 你现在装的是 | 数据怎么办 | 麻烦程度 |
|---|---|---|
| **上一代 Elychron**（包名 `xyz.nosig.celechron.mod`） | 包名不同 → **可以共存**；在 Elychron 里导出、在 Neochron 里导入即可搬过来 | ⭐ 最省事 |
| **官方 Celechron**（1.2 / 1.3 / 社区维护版，包名 `xyz.nosig.celechron`） | 两个 App 可以**共存**；待办需按下面「手动迁移」重建（官方版没有导出功能） | ⭐⭐⭐ |
| **2026-09-25 之前的早期 Neochron 构建**（包名还是 `xyz.nosig.celechron.mod`） | 与现在的新版本是两个不同的应用，**可以共存**；老的那个要卸载的话先导出数据 | ⭐⭐ |
| **Neochron → 官方版** | ❌ 不支持（官方版没有导入功能，见下） | — |

---

## 一、为什么不能"一键迁移"

官方 Celechron（含 1.2、1.3 以及社区维护版）**没有数据备份/导出功能** ——
它的设置页里只有「导出为 iCal 文件」（日历）和「导出脱敏诊断日志」，
整个仓库里也没有任何 backup / export 模块。

所以从官方版出发时，**没有任何文件能承载你的待办**。这不是我们偷懒，是对面压根没这个出口。

> 我们自己的「导出数据 / 导入数据」（设置 → 数据）**是本改版新增的功能**，
> 官方版没有，所以它只能用于「Elychron ↔ Elychron」之间。

---

## 二、情况 A：从上一代 Elychron（或早期 Neochron）搬过来

**包名不同**（Elychron 是 `xyz.nosig.celechron.mod`，Neochron 是
`io.github.specialjudge.neochron`），所以两个 App **可以共存**，数据要手动搬一次：

```text
1. Elychron：设置 → 数据 → 导出数据（得到 celechron-backup-*.json）
2. 装 Neochron（不用卸载 Elychron，两者共存）
3. Neochron：设置 → 数据 → 导入数据，选刚才那个 json
4. 打开确认：待办、标签、专注记录、自定义日程都在
```

⚠️ **为什么以前是"直接覆盖安装"，现在要搬一次**

2026-09-25 之前，Neochron 沿用着上一代 Elychron 的包名（`xyz.nosig.celechron.mod`），
那时确实是"覆盖安装、数据自动保留"。但同一个包名带来两个硬伤：
**签名不同会让覆盖安装被系统直接拒绝**（`INSTALL_FAILED_UPDATE_INCOMPATIBLE`），
**两者永远不能共存**，而且已装版本 versionCode 更大时装旧版还会被拒
（`INSTALL_FAILED_VERSION_DOWNGRADE` —— Android 只比 versionCode，不看 versionName）。
所以这一版起换成了自己的包名，代价就是**装过旧包名的人要搬一次数据**（上面四步）。
签名与密钥的说明见 [RELEASE.md](RELEASE.md)。

## 三、情况 B：从官方 Celechron 迁过来

### 3.1 自动获得的部分（占绝大多数）

登录同一个学校账号后，以下数据**由 App 自己从学校服务器拉取**，一条都不用手动搬：

| 数据 | 来源 |
|---|---|
| 课表（含下半学期、单双周、行程） | 本科教务 / 智慧研工（双来源） |
| 成绩、主修绩点、学分统计 | 本科教务 |
| 考试安排 | 本科教务 |
| 作业（学在浙大） | 学在浙大 |
| 素质拓展记点、美育 / 劳育通过状态 | 素质拓展平台 |
| 校园卡余额、付款码 | 校园卡平台 |

### 3.2 需要手动迁移的部分

**只有你自己手写的待办。** 三个办法，按推荐顺序：

**办法 1：两个 App 共存，边用边搬（最稳）**

包名不同，两个 App 可以同时装着，互不影响。你在 Elychron 里重建一条，就在官方版里删一条，
搬完再卸载官方版。

**办法 2：用 AI 整理批量重建（最快）**

Elychron 的 AI 能把**截图或一段文字**直接整理成待办（含类型、时间、地点、清单式子待办）。
把官方版里的待办列表**截图**，然后：待办页右上角 `+` → AI 整理 → 选图片，
一次能读一整屏，比手打快得多。详见 [FEATURES.md](FEATURES.md) 的「AI 整理」。

**办法 3：日历走 iCal**

官方版能「导出为 iCal 文件」。Elychron 同样能导出 iCal，也支持把课表同步到系统日历 ——
**但两边都没有"从 iCal 反过来导入待办"的功能**，所以这条只对搬日程到系统日历有用。

### 3.3 官方版数据留在哪

官方版的数据在它自己的应用私有目录里，卸载官方版即删除。Elychron 读不到、也不该读 ——
两个 App 的数据互相隔离（这正是能共存的原因）。

## 四、导出与恢复（Elychron 自己的备份）

**路径：设置 → 数据 → 导出数据 / 导入数据**

- **导出**：整份 JSON（待办、子待办、标签、标签配色、专注记录、设置、删除墓碑）存成文件，
  你可以丢到网盘、发给自己、或拷到电脑。
- **导入**：把 JSON 合并回来。**不是覆盖**，规则是：
  - 按 `uid` 配对，**更新时间较新的那份生效**；
  - 删除会留**墓碑**，所以「在一台设备删了，导入后不会又冒出来」；
  - 文件格式标识是 `celechron-mod`，只接受本改版导出的备份。

### 什么时候该导出

- **卸载 / 换手机之前**（数据在应用私有目录，卸载即删，没有回收站）
- **升级前**（万一签名不一致，覆盖安装会被拒）
- 想在新手机上延续数据时：旧机导出 → 新机导入

### 备份文件里有什么

| 字段 | 说明 |
|---|---|
| `tasks` / `tombstones` | 待办与删除记录 |
| `tags` / `tagColors` | 标签库与配色 |
| `settings` | 提醒方式、默认提前量、闹钟配色等 |
| `focusSessions` | 专注记录 |
| `deviceId` / `exportedAt` | 用来判断哪份更新 |

> ⚠️ 备份文件**不含**学校账号与密码（凭据在系统密钥库，不会写进备份）；
> 但它**包含你的待办内容**，请按隐私文件对待。

## 五、常见问题

**Q：装 Neochron 会不会覆盖我原来的 Celechron 或 Elychron？**
不会。包名都不同（Neochron 是 `io.github.specialjudge.neochron`，
官方版是 `xyz.nosig.celechron`，上一代 Elychron 是 `xyz.nosig.celechron.mod`），**可以共存**。
桌面上会有多个图标，请认准粉色那个。

**Q：装完打开是空的，是不是坏了？**
不是。第一次打开需要登录学校账号，登录后课表 / 成绩 / 作业会自动拉取。
待办是本地数据，本来就是空的（除非你导入了备份）。

**Q：登录后课表是空的？**
见 [FEATURES.md](FEATURES.md) 的「课表拿不到数据怎么办」——本改版有双来源兜底和"空数据不清空"保护，
正常情况下不会空。

**Q：我还能用官方版吗？**
能，两者互不干扰。但注意**同一份待办不会自动同步**：
本改版目前没有跨网络同步（局域网直连那套也尚未开放），
两边都用的话需要各自维护。
